# Governance

BuildAnchor is currently maintainer-led. Maintainers are responsible for project direction, releases, security response, and review quality.

Decisions should optimize for:

1. evidence-backed correctness
2. safe execution
3. portability across ecosystems and agent clients
4. a stable, documented schema
5. accessible open-source contribution

Changes to the report schema, execution policy, licensing, or security model require a documented design discussion and release-note entry.

As the contributor community grows, maintainers may establish a review team and a documented decision process through a public proposal.
