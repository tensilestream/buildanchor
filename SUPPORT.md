# Support

Use [GitHub Discussions](https://github.com/tensilestream/buildanchor/discussions) for usage questions and design conversations. Use [GitHub Issues](https://github.com/tensilestream/buildanchor/issues) for reproducible bugs and feature requests.

For security issues, follow [`SECURITY.md`](SECURITY.md) and do not create a public issue.

When reporting a bug, include the BuildAnchor version, operating system, adapter, command, sanitized report, and a minimal reproducible fixture where possible.
